# assets/icons

Coloca aquí las imágenes que quieras usar como íconos del escritorio
(`.png`, `.jpg`, `.webp`, `.svg`).

## Cómo usarlas

1. Abre **Theme → Personalizar Íconos** (o el botón de íconos en el dock).
2. En cada app pulsa **Subir Img** y elige la imagen desde este folder.

> Para que un ícono se cargue automáticamente, agrégalo en
> `assets/manifest.json` dentro del arreglo `icons`, por ejemplo:
>
> ```json
> "icons": ["assets/icons/mi-icono.png"]
> ```
>
> La app lee ese manifest al iniciar; úsalo como catálogo de referencia
> para tus íconos personalizados.
